# lifebar

OpenKakutou `lifebar` is a read/write Go library for MUGEN/Ikemen GO lifebar files (`fight.def` and the files its `[Files]` section references), decided in roadmap decision `046`. Consumers: `game` (native and web, through its shared core), `lifebar-viewer-web`, `lifebar-editor`. It compiles to WASM and has no rendering dependency, like `stage`, `sff` and `fnt`.

Part of [OpenKakutou](https://github.com/openkakutou). Early stage: see `.vibe/backlog/` for the planned work.
